## 二、几何规格（唯一事实来源）

同一个 32 单位网格，所有尺寸按比例缩放，不重画。

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 画布 | `0 0 32 32` | 方形网格 |
| 圆角 | `rx="7"` | 占边长 22%，比 iOS 图标（22.5%）略收，视觉更紧 |
| 字形占位 | `4.5 → 27.5`（23 单位） | 占画布 **72%**；留白 4.5（14%），四周均等 |
| 笔画宽度 | **5.4**（占字高 17%） | 双竖杠与斜杠统一，不因转角变粗 |
| M 的 V 底点 | y=21.2 | 到字高的 72%，不触底——小尺寸下counter（内白）更大，更易辨认 |
| 填充方式 | **实心 path** | 见下节 |

### 路径

```
M4.5 27.5V4.5h5.4L16 13.6l6.1-9.1h5.4v23h-5.4V12.1L16 21.2l-6.1-9.1v15.4z
```

### 为什么用实心而不是描边

细描边在 16px 缩放时会被抗锯齿"吃掉"一部分，笔画变灰发虚；实心轮廓降采样后仍是干净的色块边缘。
这是小尺寸字标的标准做法（Notion / Linear / Slack 的品牌块同理）。

代价：实心 M 比线条 M 视觉更重。当前侧栏底色是深绿、图标是白色，对比够，没有压迫感。

| 场景 | 尺寸 | 圆角 | 字标渲染 | 文件 |

## 四、颜色：已统一为墨绿

**2026-10-27 二次调整**：原先标签页是靛蓝 `#534AB7`、侧栏是墨绿渐变，两处不一致。现已统一到墨绿。

| 位置 | 颜色值 | 形式 |
| --- | --- | --- |
| 标签页 favicon | `#17B98F → #0E6E5C (60%) → #0A5849` | SVG `linearGradient`，从左上到右下（等价 CSS `135deg`） |
| 侧栏品牌块 | 同上 | CSS `linear-gradient(135deg, …)` |
| Safari 固定标签（mask-icon） | `#0E6E5C` | 单色剪影 |

> `theme-color` **不跟品牌色走**：它染的是移动端浏览器地址栏，应与页面底色（`#F7F6F3`）一致，用墨绿会让地址栏和页面割裂。

### 为什么选墨绿而不是靛蓝

1. 侧栏是用户停留最久的地方，那才是事实上的品牌色
2. "Miku" 本身是青绿联想（初音系）
3. 靛蓝在界面里已用作 `tag purple`（标签），当品牌色会与功能色撞车

### 颜色定义只有一处事实来源

SVG 里的渐变停止点必须与 `styles.css` 的 `.brand-mark` 完全一致，改动时**两处一起改**：

```
#17B98F  →  #0E6E5C (60%)  →  #0A5849
```

> 想整体换成别的色，改这两处 + `index.html` 的 `mask-icon color` 与 `theme-color` 即可，共 4 个位置。

## 五、使用禁区

- **不要拉伸**：宽高必须等比，M 变形后斜杠角度就废了
- **不要加描边/投影**：实心字标加描边会在小尺寸下糊成一团
- **最小尺寸 16px**：再小请改用纯色块，不放字标
- **不要给 M 换字重**：它不是字体，是画出来的路径；"加粗"要改笔画宽度并重新算 V 的交点
- **深色底才用白字标**：浅色底请改用靛蓝/墨绿字标，别用白
